# PLC-Monitor

Herramienta propia y gratuita para diagnóstico y pruebas con PLCs Siemens S7 (300/400/1200/1500):
acceso **simbólico** (S7CommPlus, con o sin TLS) y **absoluto** (PUT/GET), suscripciones, historiador,
servidor OPC UA y agentes remotos. UI de escritorio Avalonia (Windows/Linux).
